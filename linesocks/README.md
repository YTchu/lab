# LINE SOCKS mobile v3 Lite

獨立靜態上線版本，來源為 `Line_Socks_mobile_v3`，不依賴原版資料夾。

## 使用與部署

直接開啟 `index.html` 可使用；也可將本資料夾整份上傳至靜態網站主機。定位與原生分享需依瀏覽器支援並使用 HTTPS。

## 輕量版差異

- 移除選襪色功能，襪底固定使用原本預設的白色。
- 移除整個微調編輯區（`.editor.user-section.flow-panel`）：配色靈感、TRY ANOTHER、條紋數量、逐條顏色、粗細、間距及排序。
- 保留心情、天氣、情境自動生成、換活動、今日一句編輯、包裝與場景配色、PNG 下載及分享。
- 保留已儲存的字級、字型、圖示尺寸與襪子位置，以及 OFF WE GO 文案。設定 JSON 是繪製資料，不是開發面板。

## 檔案

`index.html` 是入口；`app.js` 負責繪製與匯出；`workflow.js` 負責互動流程；`scenarios.js` 內含 105 組情境；`style.css` 與 `workflow.css` 提供樣式。

## 程式清理

已移除沒有入口的開發面板、字級／圖示／襪子位置調整介面、HTML 設定存檔、停用的拖曳、黑色襪底分支、重複事件與舊分享流程、隱藏時間選擇器與套用文字按鈕、舊圖示、未使用色票和狀態，以及 101 條無對應元件的樣式。

保留可用的錯誤處理、字型載入失敗時的替代字型、定位失敗提示、分享備用面板、鍵盤焦點與響應式樣式。背景、包裝與文字配色仍可修改。字型只預載介面需要的 Noto Sans TC，其餘依已儲存字型設定載入。

## 驗證

在獨立 Chrome 中固定日期與隨機種子，比對清理前後：

- 375、768、1440px 畫面、包裝開關與分享面板截圖一致。
- 105 組情境的畫布、文字與活動圖示結果一致。
- 包裝開啟／關閉 × 4:5／9:16，四種 PNG 檔案雜湊一致。
- 心情、手動天氣、換活動、文字保留、三行限制、中文輸入與三種場景配色正常。
- 分享備用面板、複製文字、PNG 下載及匯出失敗後恢復正常。
- 以模擬瀏覽器 API 驗證原生分享成功／取消／失敗、定位成功／被拒絕及天氣回應；未代替使用者實際傳送分享內容。
- 比對環境封鎖外部字型請求，以確認字型無法連線時仍可操作；實機系統分享與線上字型呈現仍依裝置／網路支援而定。
- 無 JavaScript 執行錯誤；本機引用不依賴原版資料夾。
